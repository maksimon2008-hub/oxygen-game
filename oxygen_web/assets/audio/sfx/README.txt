ЗВУКОВЫЕ ЭФФЕКТЫ OXYGEN

Замени WAV-файлы своими, сохранив точные имена:
- shoot.wav — выстрел CIPHER / AERIS
- dash.wav — рывок VANTA
- double_jump.wav — второй прыжок ECHO
- flight.wav — зацикленный звук полёта AERIS
- coin.wav — подбор монеты и тайника x2
- achievement.wav — всплывающее уведомление об открытии достижения

Рекомендуемый формат: WAV PCM, 16-bit, 22050 Hz, mono. Звук достижения уже подключён; его можно заменить собственным.
