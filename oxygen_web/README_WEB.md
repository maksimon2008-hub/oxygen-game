# OXYGEN WEB — Python + WebAssembly

Это параллельная браузерная сборка OXYGEN на базе исходного Pygame CE проекта. Windows-версия не изменена.

## Запуск на Windows

1. Установи Python 3.12 x64.
2. Распакуй весь архив, сохранив структуру папок.
3. Открой `oxygen_web` и запусти `run_web.bat`.
4. При первом запуске Pygbag установится автоматически.
5. Дождись сборки и открой `http://localhost:8000` (если браузер не открылся сам).
6. Нажми по игровому окну, чтобы браузер разрешил звук и клавиатурный ввод.

Нужен интернет при первой установке Pygbag и загрузке WebAssembly runtime. Для публикации сервер должен отдавать файлы через HTTP(S); запуск через `file://` не подходит.

## Что уже адаптировано

- Асинхронный игровой цикл с `await asyncio.sleep(0)` для браузерного event loop.
- Ограничение 60 FPS в WebAssembly; десктопная версия сохраняет собственный лимит.
- Отдельный persistent save path `/data/savegame.json` для браузерного хранилища Pygbag.
- Браузерная версия звуковых эффектов в OGG Vorbis; desktop WAV-версии остаются в основной Windows-папке проекта.
- Фиксированный canvas 1100×620; масштабирование выполняется окном/страницей.
- Полноэкранное переключение оставлено управлению браузера.

## Важно

Это первая техническая WebAssembly-адаптация, а не подтверждённый релиз. Сборку необходимо проверить в реальном браузере на Windows: ввод, аудио, загрузку ресурсов, сохранения после перезагрузки страницы и производительность. Отдельные особенности SDL/Pygame в браузере могут потребовать корректировок.

## Публикация

После успешного локального теста можно публиковать web-выход Pygbag на GitHub Pages или itch.io. Не загружай исходный ZIP как готовую браузерную игру: нужен именно собранный web output.
